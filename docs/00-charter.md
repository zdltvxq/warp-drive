## 3. 项目定位（一句话）

把曲率引擎（Alcubierre 型超光速时空泡）当成一个工程问题来审计：
先写成可计算的，再让数字说明它卡在哪。**这不是造飞船的承诺书**，是可复算的可行性审计。

## 4. 范围

做的：

- 3+1 ADM 求解器（平切片 → 后续通用切片），能量密度、膨胀、潮汐的数值与解析对拍
- 设计空间扫描：载荷半径、舰体包络、巡航速度、壁厚
- 量子不等式、能量条件、视界与因果的定量审计
- 每一阶段的 go / kill 判据

不做的：

- 不做"正能量曲率引擎已可行"的宣传；文献里的争议按 `docs/03-open-problems.md` 并列呈现
- 不提供任何可用于危险用途的工程参数（本项目的物理结论是"当前物理下不可实现"）
- 不追热点式的数值美化；所有数字必须能从 `scripts/audit.py` 复现
