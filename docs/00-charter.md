## 3. 项目目标

用可复算的模型评估 Alcubierre 型曲率泡的能量需求与物理限制。建造飞船不在项目范围内。

## 4. 范围

- 开发 3+1 ADM 求解器。先验证平切片上的能量密度和膨胀率，再扩展到一般切片和潮汐力计算。
- 比较载荷半径、舰体包络、巡航速度和壁厚对能量需求的影响。能量估算应能由 `scripts/audit.py` 复算。
- 检查量子不等式、能量条件、视界与因果性。文献分歧见 `docs/03-open-problems.md`；各阶段的验收和停止条件见 `docs/02-plan.md`。
- 不提供可用于危险用途的工程参数。
