# 01 设计：曲率引擎的物理基线与设计空间

## 1. 任务假设

| 项 | 取值 | 理由 |
|---|---|---|
| 目标 | 半人马座 α（4.246 ly） | 最近的恒星系，可测量的真实目标 |
| 巡航速度 | 10c（基线），1c / 100c 作灵敏度 | 10c 时 0.43 年抵达；1c 时 4.25 年 |
| 载荷舱半径 | 10 m | 一个乘员舱 + 生保的合理量级 |

固定泡形和尺寸，从 1c 提到 10c 会把巡航时间缩短到十分之一，所需负能量的绝对值则增至 100 倍。后文把速度和壁厚分开比较。

## 2. 度规族与 3+1 分解

基线模型取平切片、lapse α=1，沿 x 轴直线巡航：

```
ds² = -dt² + (dx - v f(r) dt)² + dy² + dz²
β^x = -v f(r),  β^y = β^z = 0,  γ_ij = δ_ij,  α = 1
r² = X² + y² + z²,  X = x - x_s
```

这个度规有已知的能量密度解析式，可以用来检验网格求解器。Phase 1 再扩展到一般切片。

### 2.1 外曲率

γ=δ 且与时间无关 ⇒ 空间联络为零、∂_t γ = 0：

```
K_ij = (1/2α)(∂_i β_j + ∂_j β_i)
K_xx = -v f' X/r ,  K_xy = -(v/2) f' y/r ,  K_xz = -(v/2) f' z/r
K_ji = K_ij，其余为零；tr K = -v f' X/r
```

### 2.2 欧拉观察者的能量密度

平切片下 3-Ricci 标量为零，哈密顿约束退化为

```
ρ_E ≡ T^{ab} n_a n_b = (K² - K_ij K^ij) / 16π
     = -(v²/32π) · (y²+z²)/r² · f'(r)²
```

测试用 Alcubierre（1994，式 18）检查网格结果。在泡壁内，`v` 和 `f′` 不为零时，轴外的欧拉能量密度为负，因此该度规违反弱能量条件（WEC）。这个结论不要求 `f` 取 tanh 形状。

### 2.3 体积膨胀率与总能量

```
θ = -α tr K = v (X/r) f'(r)        （泡前收缩、泡后膨胀）
E = ∫ρ_E d³x = -(v²/12) ∫₀^∞ f'(r)² r² dr      （用 <(y²+z²)/r²> = 2/3）
```

参数扫描用一维积分计算总能量；验证时再与三维网格的积分结果比较。

## 3. 设计参数与能量审计

### 3.1 形状族

| 形状 | 定义 | 特点 |
|---|---|---|
| Alcubierre tanh | `f = [tanh σ(r+R) - tanh σ(r-R)] / (2 tanh σR)` | 经典；f(0)=1 与 σ 无关；指数尾迹 |
| compact smootherstep | `f = 1 - smootherstep((r-r_in)/(r_out-r_in))` | C²、紧支撑；壁厚为 `r_out − r_in` |
| 高斯壳 | `f = exp(-(r/s)^4)` | 平滑；要求尺度参数 `s ≥ 5.6 r_ship` |

在同一包络（r_out = 2 r_ship）下，取载荷半径 10 m、速度 1c。代码对 tanh 形状只检查包络处的衰减，并未要求整个载荷区内 `f ≈ 1`；因此这里的最低能量不代表已满足舱内条件。

| 族 | 总能量 | 等效质量（绝对值） | 比较 |
|---|---|---|---|
| tanh | -0.989 m = -1.20×10⁴⁴ J | 1.33×10²⁷ kg | 最省 |
| compact smootherstep | -2.71 m = -3.27×10⁴⁴ J | 3.64×10²⁷ kg | 能量绝对值约为 tanh 的 2.7 倍 |
| 高斯壳 | — | — | 不满足该包络下的衰减要求 |

在这个包络下，两种可用形状的能量需求相差不到一个数量级。第 4 节单独比较壁厚的影响。

### 3.2 包络与最佳壁厚（v = 1c, r_ship = 10 m）

| r_out / r_ship | σ (1/m) | 总能量 | 等效质量（绝对值） |
|---|---|---|---|
| 1.2 | 1.727 | -4.80 m = -5.81×10⁴⁴ J | 6.47×10²⁷ kg |
| 1.5 | 0.691 | -1.93 m = -2.34×10⁴⁴ J | 2.60×10²⁷ kg |
| 2.0 | 0.345 | -0.989 m = -1.20×10⁴⁴ J | 1.33×10²⁷ kg |

| 5.0 | 0.090 | -0.588 m = -7.12×10⁴³ J | 7.92×10²⁶ kg |

## 4. 量子不等式与薄壁估算

前面的扫描不施加量子不等式（QI）。Pfenning 和 Ford（1997）用 QI 限制观测者沿世界线采样到的负能量，在其模型中得到的泡壁厚度上限约为几百个普朗克长度。

下表采用指定壁厚，以同一径向积分的薄壁近似估算能量（r_ship = 10 m，v = 1c）。表中各行并不代表相应壁厚已满足 QI：

| 壁厚 | 总能量 | 等效质量（绝对值） |
|---|---|---|
| 10 ℓ_P | -1.72×10³⁴ m = -1.16×10³¹ M_☉ | 2.31×10⁶¹ kg |
| 100 ℓ_P | -1.72×10³³ m = -1.16×10³⁰ M_☉ | 2.31×10⁶⁰ kg |
| 1000 ℓ_P | -1.72×10³² m = -1.16×10²⁹ M_☉ | 2.31×10⁵⁹ kg |

在固定半径和速度的薄壁近似下，能量绝对值与壁厚成反比。若某个方案需要更厚的壁，应先检查 Pfenning 和 Ford 的推导条件是否适用。

## 6. 求解器的适用范围

`flatslice.py` 要求 γ=δ，因此空间 Ricci 标量为零。代码可接收正的 lapse 场；本页的 Alcubierre 基线取 α=1。Phase 1 扩展到非平切片时需要：

- 逆 3-度规、Christoffel 符号、3-Ricci 标量（数值四阶差分）
- 哈密顿约束的完整形式 `ρ_E = (³R + K² - K_ijK^ij)/16π`
- 没有解析解时，用网格收敛性与已知的平坦、静态极限验证
