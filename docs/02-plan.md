# 02 实施计划

每个阶段都要说明如何复算结果，以及在什么条件下继续或停止。

## Phase 0 — 可复算的物理基线（已完成，v0.1）

交付物：

- 平切片 ADM 求解器：由 shift 和 lapse 计算 K_ij、tr K、θ、ρ_E
- Alcubierre 能量密度解析式、一维能量积分及三维网格验证
- 对给定载荷半径扫描包络和速度，比较各形状的负能量需求
- 文档：`docs/01-design.md`

判定（已通过）：

- 与 1994 eq.18 逐点一致（相对误差 < 5×10⁻⁴）
- 网格收敛观测阶 > 3
- E ∝ v² 到 1e-6

## Phase 1 — 扩展求解器并复现文献结果（4–6 周，软件）

当前数值验证针对 Alcubierre 基线。要比较其他度规，需要先让求解器处理一般切片，再复现文献结果。Natário 的零膨胀解也可用来检验不同的 shift 场。

任务：

1. 通用 3+1 求解器：任意 γ_ij(x)（正定）、α(x)、β^i(x)
   - 数值逆 3-度规、Christoffel、³R（四阶差分）
   - `ρ_E = (³R + K² - K_ijK^ij)/16π`、`θ = -α tr K`
   - 验证手段改为：收敛阶、静态/平坦极限、与平切片族的一致性交叉检查
2. 复现三篇代表性解并在同一张表上比 E、WEC 违反度、QI 相容性：
   - Van den Broeck 1999（体积压缩，"几倍太阳质量"）
   - Lentz 2020（Einstein–Maxwell–plasma 孤子，宣称正能）
   - Natário 2001（零膨胀族）
3. 用舱内 Riemann 张量估算潮汐力，得到壁厚下限，再与 C4 的 QI 上限比较。
4. 视界检测：类光测地线 + 蓝移因子扫描（Natário 2001 §3 的数值版）

验收条件：三个代表性解的能量估算均在原文数值的两倍范围内，并得到可与 QI 上限比较的潮汐壁厚下限。

暂停条件：若结果与原文相差超过 3 个数量级，又未发现代码原因，先核对原文假设再继续。

## Phase 2 — 源类别审计（4 周，软件 + 文献）

对其他度规，单个欧拉观察者测得非负密度还不足以验证 WEC。按 Santiago、Schuster 和 Visser（arXiv:2105.03079）的分析，WEC 要求对所有类时方向检查能量密度。

任务：

1. 给定候选源的 `T_{ab}`，对未来指向的单位类时向量 `u^a` 扫描方向和速度，寻找使 `T_{ab}u^a u^b < 0` 的反例。有限扫描不能证明 WEC 成立。
2. 分别报告欧拉观察者的能量密度、WEC 检查结果，以及针对类光向量的 NEC 检查结果。
3. 在同一张表里列出各候选源违反的条件和尚未判定的条件。

验收条件：指出至少一个尚未被 NEC 检查排除的候选类别，或为 Phase 4 给出 NEC 违反量的定量下界。

停止条件：若所有候选类别都违反 NEC，跳到 Phase 4，整理适用于这些类别的限制。

## Phase 3 — 实验室可及的证伪路径（持续，外协）

先评估下列实验能测到什么，以及测量结果能检验模型的哪项假设：

1. Casimir / 压缩光：现有负能量密度的量级、持续时间、以及 QI 的实测进展
2. 类比引力（BEC、非线性光学、超材料）：检查系统能否复现等效的 K_ij 与 θ，以及能否检验不稳定性判据。
3. 高精度引力实验：曲率泡对邻近质量的引力特征（若存在微弱残留场）
4. 对每项实验列出观测量、所需精度和什么结果能排除模型。

验收条件：至少一条路径能在 5 年内给出可解释的实验结果，包括有检出限的零结果。

停止条件：若三条实验路径都没有可测信号，后续工作限于理论分析。

## Phase 4 — 判定（2 周，写作）

根据前几阶段的结果，选择一项交付：

- A. 不可能性界：在明确列出的 GR、QFT 和 QI 假设下，找出对所研究的超光速泡互不相容的约束，给出定量不等式，并与现有实验限制比较。
- B. 新物理需求清单：列出避开已知限制需要更改的假设（如 Lorentz 不变性、QI、能量条件或经典时空），说明各项更改有哪些可检验的后果。

验收条件：写成一篇可供同行审查的 10–20 页文档，并提供计算结果的复算方法。

## 当前已知的工作量级

- Phase 1 的通用求解器：约 600–900 行（逆度规、联络、³R、潮汐、测地线）
- 计算量：单次 3D 求解（241³）在本机约 15 s；参数扫描用一维积分，秒级
- 不需要 GPU，不需要外部算力
