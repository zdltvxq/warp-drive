# 02 实施计划

原则：每个阶段都必须以"能被同行用仓库里的代码复算"为交付物，
并且带一个**能杀死本阶段**的判据（kill criterion）。没有判据的阶段不立项。

---

## Phase 0 — 可复算的物理基线（已完成，v0.1）

交付物：

- 平切片 ADM 求解器（任意 shift/apse 场 → K_ij、tr K、θ、ρ_E）
- Alcubierre 闭式解 + 能量一维积分，与网格解对拍到 3×10⁻⁴
- 设计空间扫描：载荷半径 × 包络 × 速度 → 最省泡
- 文档：`docs/01-design.md`

判定（已通过）：

- 与 1994 eq.18 逐点一致（相对误差 < 5×10⁻⁴）
- 网格收敛观测阶 > 3
- E ∝ v² 到 1e-6

## Phase 1 — 摆脱平切片特例（4–6 周，纯软件）

为什么必须先做：现在所有结论都在 γ=δ、α=1 的族里成立。文献里的"正能量曲率引擎"
（Bobrick–Martire 型、Lentz 2020 柱对称孤子、Van den Broeck 1999 的体积压缩）
全都不在这个族里。只在平切片上论证"不行"，反方一句话就能驳掉。

任务：

1. 通用 3+1 求解器：任意 γ_ij(x)（正定）、α(x)、β^i(x)
   - 数值逆 3-度规、Christoffel、³R（四阶差分）
   - `ρ_E = (³R + K² - K_ijK^ij)/16π`、`θ = -α tr K`
   - 验证手段改为：收敛阶、静态/平坦极限、与平切片族的一致性交叉检查
2. 复现三篇代表性解并在同一张表上比 E、WEC 违反度、QI 相容性：
   - Van den Broeck 1999（体积压缩，"几倍太阳质量"）
   - Lentz 2020（Einstein–Maxwell–plasma 孤子，宣称正能）
   - Natário 2001（零膨胀族）
3. 潮汐张量：舱内 Riemann 分量 → 乘员可承受的壁厚下限（与 C4 的 QI 上限对夹）
4. 视界检测：类光测地线 + 蓝移因子扫描（Natário 2001 §3 的数值版）

Go 判据：三个代表性解的能量量级被独立复现（与原文数量级一致，允许因子 2 内差异），
且潮汐约束给出的壁厚下限是**有意义的**（不是"任意厚都行"）。

Kill 判据：若复现结果与原文差 3 个数量级以上且找不到代码原因 —— 停下重读原文的假设，
不要在错误的基线上继续叠代。

## Phase 2 — 源类别审计（4 周，软件 + 文献）

问题：`ρ_E < 0` 是几何恒等式给的，那么"源"能不能是正能量的？
Santiago, Schuster & Visser (arXiv:2105.03079) 的答案是：WEC 要求**所有**类时观察者
都看到正密度，而那些"正能量"论文只证明了共动欧拉观察者看到正密度。

任务：

1. 对每个候选源类别，计算全套观察者的能量密度下界（把 n^a 扫过未来光锥）。
   这是本仓库求解器的一个直接扩展：给定 T_{ab}，对 n^a 做球面扫描取最小值。
2. 复核三类主张：(a) 共动观察者正能；(b) 全观察者正能；(c) NEC（类光）。
   三者强度递增，文献里常被混用。
3. 输出"哪一类源在哪个能量条件下活着"的表格。

Go 判据：能明确指出至少一个类别在 **NEC** 层面未被排除，或者给出 NEC 违反的定量下界
（这样 Phase 4 的不可能性定理才有输入）。

Kill 判据：所有类别在 NEC 层面全部死亡 ⇒ 直接跳到 Phase 4，写不可能性界，
不浪费时间在工程化上。

## Phase 3 — 实验室可及的证伪路径（持续，外协）

曲率引擎在实验室里唯一可能触及的部分是**负能量的量子实现**与**类比时空**：

1. Casimir / 压缩光：现有负能量密度的量级、持续时间、以及 QI 的实测进展
2. 类比引力（BEC、非线性光学、超材料）：能否造出等效的 K_ij 与 θ 场，
   在类比系统里"跑"一个曲率泡的不稳定性判据
3. 高精度引力实验：曲率泡对邻近质量的引力特征（若存在微弱残留场）
4. 明确的证伪命题：给出"若 X 在 Y 精度下不为零 → 本项目路线错误"的清单

Go 判据：至少一条路径能在 5 年内给出可测的负结果（负结果也是结果）。

Kill 判据：三条路径全部无法在实验室尺度上产生任何可测差别 ⇒ 项目降级为纯理论，
不再声称工程可行性。

## Phase 4 — 判定（2 周，写作）

二选一，必须明确交付其中一个：

- **A. 不可能性界**：在标准 GR + QFT + QI 下，任何 v > c 的泡需要壁厚 < 某尺度，
  而 QI 禁止 —— 给出数值化的不等式，说明它比现有实验极限严格多少个数量级。
- **B. 新物理需求清单**：若要绕开，必须放弃哪一条（Lorentz 不变性 / QI / 能量条件 /
  经典时空），每条给出可检验的副作用。

Go 判据：能写成一篇可供同行审查的 10–20 页文档，且所有数字由本仓库生成。
